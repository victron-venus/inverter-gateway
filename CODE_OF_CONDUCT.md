# Community conduct

Participants in inverter-gateway are expected to be respectful, considerate and constructive. Critique ideas and code, respect different experience levels, and protect other people's privacy. Harassment, threats, discriminatory abuse, sexualized conduct and publishing private information without permission are not acceptable. These expectations apply to project issues, pull requests, discussions and other project spaces.

## Private reports and enforcement

Report conduct concerns privately to the maintainer at **alvit.work@gmail.com**. Include links, relevant context and your preferred contact method. Do not put sensitive reports in a public issue. The maintainer will review reports, protect confidentiality as far as practical, and apply proportionate action such as a warning, content removal, temporary restriction or exclusion. Retaliation for a good-faith report is prohibited.

Explain disagreements about enforcement privately through the same contact. This project currently has one enforcement contact and no independent escalation reviewer; it does not promise independent arbitration. Report software vulnerabilities using [SECURITY.md](SECURITY.md).
